# 🧑🏻‍💻 Gabriel Birk

Tenho 25 anos, moro na cidade de Novo Hamburgo no Rio Grande do Sul e sou estudante de **Engenharia de Software**. Sou movido por curiosidade e pela vontade de aprender. Sempre gostei de olhar para o caos e encontrar ordem, e enxerguei na área de dados a oportunidade perfeita para fazer exatamente isso. Descobri que números e bancos de dados não servem apenas para guardar registros, mas sim para contar histórias e direcionar as melhores decisões.
Atualmente, concentro meus estudos e projetos em **Python, SQL e Análise de Dados**, explorando desde a manipulação e limpeza de dados até a construção de pipelines e painéis analíticos.
